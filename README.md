# 2D Top-down Game Prototype

这是一个用 Python + Pygame API 构建的 2D 上帝视角游戏原型。

## 运行

```powershell
pip install -r requirements.txt
python main.py
```

## 操作

- `WASD` 或方向键：移动角色
- 鼠标指向：改变射击方向
- 小键盘 `8/2/4/6` 或 `7/9/1/3`：改变射击方向
- `空格键`：点按发射，也可以按住连续发射
- 鼠标左键：发射一次
- 鼠标滚轮：切换主/副武器
- `X`：切换主/副武器
- `Esc`：退出游戏
- `R`：死亡后重新开始

## 当前玩法

- 地图中央绿色区域是安全区。
- 玩家第一次离开安全区后，安全区会消失。
- 玩家离开安全区后，如果场上没有敌人，会生成 `1` 到 `3` 个红色敌人。
- 敌人初始有 `3` 点血量，蓝色子弹默认命中 `3` 次后击杀。
- 敌人碰到玩家会攻击，每次造成 `25` 点伤害。
- 玩家初始血量是 `100 HP`，左上角绿色血条会显示当前血量。
- 击败敌人后会累计击杀数。
- 每击败 `5` 个敌人，之后生成敌人的数量和血量都会增加。
- 阶段目标按 `15`、`30`、`45` 名击杀依次推进。
- 每完成一个阶段，会清空敌人并进入 `10` 秒安全时间，这段时间不会生成敌人。
- 每个新阶段开局的第一波敌人数会回到初始 `1` 到 `3` 个，但敌人血量成长会继承。
- 首次运行会自动生成 `assets/battlefield.png` 作为战场背景，让场地不再只有单一网格。
- 战场会随机生成强化道具：
  - `B`：子弹变粗 `+1`
  - `S`：子弹速度等级 `+1`
  - `D`：子弹伤害 `+1`
- `H`：回复 `50 HP`，生成概率是基础强化道具总概率的一半。
- 掉落物存在 `30` 秒；`20` 秒后开始闪烁；最后 `10` 秒越接近消失闪烁越快。
- 场上已有 `3` 个未拾取的普通强化/回复/特殊道具时，不会继续生成这类道具。
- 武器道具：
  - `SG`：散弹枪，向瞄准方向发射扇形 `5` 发子弹；子弹大小是初始子弹 `2` 倍，每颗伤害是当前基础伤害的 `1.5` 倍，并继承已有强化。
  - `MG`：机关枪，获得 `2` 倍攻速；子弹伤害是当前基础伤害的 `1.25` 倍，子弹大小是初始子弹 `1.5` 倍，并继承已有强化。
  - `L`：射线枪，发射从角色到屏幕边界的线性贯穿射线；粗细等于当前基础子弹粗细，射线上接触到的所有敌人都会受到当前基础伤害 `0.75` 倍的伤害。
- 武器栏：
  - 开局 `1` 号栏是初始武器，`2` 号栏为空。
  - 拾到第一个新武器会放入 `2` 号栏并自动切到该武器。
  - 鼠标滚轮或 `X` 可以切换武器。
  - 场上已有 `2` 个未拾取的武器掉落时，不会继续生成武器。
  - 拾到与任意武器栏相同的武器时，不替换栏位，而是强化该武器的子弹大小、速度、伤害各 `+1`。
  - 两个武器栏都已占用且拾到全新的武器时，会替换当前正在使用的武器。
- `SS`：Super shoot，生成权重为 `0.33`，拾取后当前整体伤害和射速乘数都变为原来的 `300%`。
- `I`：无敌道具，拾取后无敌 `30` 秒，身体碰到敌人时会反弹伤害。
- 游戏会程序生成武器发射、命中、拾取和切换音效，不需要额外音频文件。
